🚀 Running the Project

You don't need to install anything to run the portfolio.

Clone the repository:

git clone https://github.com/stryker461-cpu/HazeemPortfolio.git


Then open the project folder and run index.html in your browser.

If you're using VS Code, you can use Live Server while making changes.

🎨 Design

The portfolio is designed to keep things simple and focused on the content.

The layout is responsive, so the website can be viewed on desktops, tablets, and mobile devices without needing a separate mobile version.

📱 Responsive

The website is built to adapt to different screen sizes.

The layout, spacing, navigation, and content adjust automatically depending on the device being used.

🔧 Customization

Most of the content can be changed directly in index.html.

The visual styling can be modified in:

style.css


Interactive behavior and JavaScript functionality can be found in:

script.js
