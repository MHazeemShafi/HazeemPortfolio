🖥️ About The Project

HazeemPortfolio is a personal portfolio website created entirely from scratch using HTML, CSS, and JavaScript.

The goal was to create something that feels:

Simple. Modern. Responsive. Personal.

Instead of relying on frameworks or pre-built templates, the entire interface is built using core web technologies, giving me complete control over the design, layout, animations, and interactions.

🎨 Design Philosophy

The design follows a simple principle:

┌───────────────────────────────┐
│                               │

│                               │
│       MAKE IT PERSONAL.       │
│                               │
│       MAKE IT RESPONSIVE.     │
│                               │
└───────────────────────────────┘


The interface is intentionally focused on the content rather than unnecessary visual clutter.

Design Goals

✦ Minimal visual clutter

✦ Clear navigation

✦ Consistent spacing

✦ Responsive layouts
